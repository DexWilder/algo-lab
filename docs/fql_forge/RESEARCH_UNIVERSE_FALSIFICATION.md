# What evidence would convince us we're searching in the wrong universe? (2026-07-07)

The uncomfortable question, pre-registered so we can't dodge it later. The current universe = **micro futures (MNQ/MES/MYM + rates/FX/metals/energy), daily–weekly horizon, structural-mechanism edges, retail-ish cost.** If that universe is wrong, no amount of packet-running finds alpha; we'd just refine the same losing assumptions indefinitely.

## Three live hypotheses (from the kill autopsy)
- **H-edge** — durable structural edges are genuinely rare (maybe ~2 standalone + ~8 filters per 100 real hypotheses).
- **H-observability** — the edges exist but we've only tested proxies + coarse-direct measurements; **0 high-resolution direct measurements tested to date.**
- **H-universe** — we're in the wrong market / horizon / return-target / cost regime entirely.

These are not mutually exclusive, but they imply *different next moves*, so we must actively try to separate them.

## Pre-registered decision rules

**Test 1 — the observability discriminator (run first).** Convert 3 proxy-kills into high-resolution DIRECT tests, framed as conditioners: (a) dealer gamma via real IV surface (held option settlements → BS-invert), (b) one acquired direct measurement (VX term structure OR single-name IV for dispersion), (c) skew from the real IV surface.
- **≥1 survives OOS as a conditioner** → **H-observability supported.** Direction confirmed: pour resources into high-resolution direct data. NOT wrong universe.
- **ALL 3 clean-kill** (DSR<0.7 AND no OOS filter value) → **H-observability falsified.** The edge is not hiding in resolution → escalate to Test 2.

**Test 2 — the universe check (only if Test 1 falsifies observability).** Before concluding "no alpha here," test whether the *universe axes* are wrong, one at a time:
- **Horizon:** the autopsy says intraday is worst (12%) and daily-weekly conditioning is best (71%). So the horizon rethink is UP not down — test **multi-week / monthly macro-conditioned** books, not HFT.
- **Return target:** we've chased *directional* futures PnL. The survivors are conditioners/relative-value. Rethink toward **vol / dispersion / carry books** where the edge is structural, not directional.
- **Cost regime:** the overnight anomaly was real gross, dead net. If ≥2 more mechanisms show the *same gross-alive/net-dead signature*, the binding constraint is **execution/capacity, not signal** — a fundamentally different problem (needs cheaper execution or larger size, not better ideas).
- **Asset class:** if micro-futures conditioners keep dying but the *mechanisms* are sound, the venue may be wrong (single-name equities, credit, crypto-native have richer forced-flow observability).

## The hard kill criterion for the current program
**If, after Test 1 (3 high-resolution direct conditioners) AND a first pass of Test 2 (horizon-up + return-target-shift), we still have 0 OOS-surviving conditioners across ~10 genuinely-direct, genuinely-conditioning mechanisms — then the current-universe assumption is falsified.** At that point the honest move is NOT another harvest cycle; it is a documented decision to change the universe (venue or return-target), or to conclude that our data/cost tier cannot access the edges that exist and stop spending on the current loop.

## What would make us KEEP the current universe (the positive case)
- Test 1 produces ≥1 OOS-surviving direct conditioner, OR
- The provisional funding-stress filter (passed OOS: DD −18%, Sharpe +0.16 in H2) is joined by ≥2 more OOS-validated conditioning overlays → the "6 mediocre orthogonal filters > 1 workhorse" portfolio thesis becomes buildable, which is itself a valid product even with 0 standalone workhorses.

## Interpretation discipline (pre-registered — binds BOTH outcomes, written before running)
The outcome must *update* beliefs, not *determine* them. Guardrails locked in advance so neither result can be over-read:
1. **N≥3 before any observability conclusion.** One discriminator settles nothing. The observability hypothesis is only supported/weakened after ≥3 *independent* direct-vs-proxy pairs (dealer gamma, dispersion/single-name IV, one more). A single survivor supports observability **for that mechanism only** — never a universal law ("all structural-flow ideas are good"). A single death weakens it **for that mechanism only** — never "no durable edges exist anywhere."
2. **The autopsy is a prior, not a law.** "Conditioning survived 71% *in this program so far*" ≠ "conditioning always works." `survivor_fit` is a **priority ordering**, not a filter or a truth-claim. We still test outright/price mechanisms — just ordered lower. We do not refuse a hypothesis because it scores low.
3. **Do NOT become "the direct-data lab."** Direct measurement is ONE promising direction, not the only one. PRICE-only survived 28% (not 0), and cross-market **trend-following is a decades-proven counterexample built entirely from price.** A price-native track (trend/momentum across the futures set, done properly) stays alive in parallel — deprioritized, not abandoned.
4. **Symmetric standard.** The pre-committed reading of BOTH outcomes (below, per experiment) is written before the run. If I find myself explaining a result in a way I didn't pre-register, that's the tell I'm rationalizing.
